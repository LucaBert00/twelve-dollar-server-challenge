## 1. Domain terms (fixed for #7–#9 consumers)

- `candidate`: needs its Validation experiment before any adopt claim. `adopted`: baseline policy/gate in force regardless of measurement (correctness, rules, harness). `validated`: measured on the target box under the #8 harness — none yet. `rejected`: prohibited by rules OR disqualified as guidance (quarantined figures).
- Splits: `safe-baseline` = adopt now, zero rule risk, zero SPEC-edge risk. `experimental` = one variable per run, golden-byte + rule gates per run, rollback criterion stated. `high-risk` = structural/portability/SPEC-edge risk; late-stage only, only if headroom demands, explicit falsifier. `prohibited` = rule-verified forbidden, never tested.
- `Rule compat`: `allowed` = no rule speaks against it (gates may still apply). `prohibited` = a numbered rule forbids it. `uncertain` = rule-silent but interaction unanalyzed — needs #9 line review before any run.
